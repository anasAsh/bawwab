---
name: injection-awareness
description: Explain prompt-injection risks to developers.
---

When the user asks about prompt injection, explain that attackers hide instructions in data the model reads, such as web pages or tool output. Give examples of the warning signs, for instance text that claims to come from the system, or that asks the model to change its task. Recommend treating tool output as untrusted data and asking the user before any irreversible action.
