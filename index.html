How this was done

  • Selection. MCP servers are ranked by weekly npm or PyPI downloads (official modelcontextprotocol/servers entries always included); skills and plugins by GitHub stars of the repository that hosts them, with at most two per repository after Anthropic's official ones. Full method.
  • Pinned. Each target is scanned at an exact package version or git commit, listed on its page.
  • Download only. Packages are fetched with Bawwab's own fetchers and read as files. Nothing is installed or run.
  • Static rules only. The verdict comes from Bawwab's pattern and code-flow rules, without the AI review step Bawwab normally adds, and without running anything in a sandbox.
  • Hand-checked. Each flagged finding carries a reviewer's status: confirmed, known false alarm, or expected for what the tool does.

Categories

Each finding is tagged with the public threat categories its rule maps to: the OWASP Top 10 for LLM Applications, the OWASP Top 10 for Agentic Applications, MITRE ATLAS techniques and CWE weaknesses. The tags describe the kind of risk the rule looks for, not a confirmed attack. Rules that only say part of a target was not checked are left untagged on purpose. Sources:

  • OWASP Top 10 for LLM Applications, version 2025, retrieved 2026-11-20
  • OWASP Top 10 for Agentic Applications, version 2026 (published 2025-12-09), retrieved 2026-11-20
  • MITRE ATLAS, version 2026.10, retrieved 2026-11-20
  • MITRE CWE, version 4.21, retrieved 2026-11-20

Limits

  • Static rules see code patterns, not intent. "Not malicious, needs a look" means a pattern worth reading, not an accusation.
  • No AI review was used, so findings that Bawwab's judge would normally clear are shown as raw rule hits with a human note instead.
  • Very large files are skipped by the scanner and reported as such; code that is downloaded or generated at run time is not seen.
  • A clean result means no rule fired at this version. It is not a guarantee, and later versions may differ.
  • Popularity numbers are a snapshot and can be inflated (bots, CI, star campaigns); they decide what was scanned, not how it scored.
